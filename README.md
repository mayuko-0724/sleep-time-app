# 睡眠時間記録アプリ

## システムの概要

「睡眠時間記録アプリ」は、就寝時刻と起床時刻を入力すると、自動で睡眠時間を計算し、睡眠時間に応じた簡単なコメントを表示するWebアプリケーションです。

Dockerコンテナ上で動作し、ホストPCのブラウザから利用できます。大学の課題で、ChatGPTを用いたVibe codingにより作成しました。

## 用途

このアプリは、自分の睡眠時間を簡単に記録し、日々の生活リズムを見直すために使用します。

主な用途は以下の通りです。

- 就寝時刻と起床時刻の記録
- 睡眠時間の自動計算
- 睡眠時間に応じた簡単なコメント表示
- 過去の睡眠記録の確認
- 記録数と平均睡眠時間の確認

※このアプリは学習課題用に作成したものであり、医療的な診断や治療を目的としたものではありません。

## 主な機能

- 睡眠記録の追加
- 睡眠時間の自動計算
- 睡眠時間の判定コメント表示
- 最近の睡眠記録一覧表示
- 平均睡眠時間の表示
- 睡眠記録の削除

## 入力・処理・出力

### 入力

ユーザーは以下の情報を入力します。

- 日付
- 就寝時刻
- 起床時刻
- メモ（任意）

### 処理

入力された就寝時刻と起床時刻から睡眠時間を計算します。  
起床時刻が就寝時刻より早い場合は、日付をまたいで起床したものとして計算します。

例：  
23:30に就寝し、7:00に起床した場合、睡眠時間は7時間30分になります。

また、睡眠時間に応じて「短め」「標準」「長め」のようなコメントを表示します。

### 出力

以下の内容を画面に表示します。

- 計算された睡眠時間
- 睡眠時間に対するコメント
- 最近の睡眠記録
- 記録数
- 平均睡眠時間

## 実行方法

このアプリはDockerコンテナ上で動作します。

事前にDocker Desktopを起動したうえで、以下の手順で実行します。

### 1. リポジトリを取得する

GitHubからソースコードを取得します。

```bash
git clone https://github.com/mayuko-0724/sleep-time-app.git
```

取得したフォルダに移動します。

```bash
cd sleep-time-app
```

### 2. Dockerコンテナを起動する

以下のコマンドを実行します。

```bash
docker compose -p sleep-time-app up --build
```

このコマンドにより、Dockerイメージの作成、必要なライブラリのインストール、Flaskアプリの起動が行われます。

起動中は、ターミナルにFlaskの実行ログが表示されます。  
アプリを利用している間は、このターミナルを閉じずにそのままにします。

### 3. ブラウザでアクセスする

コンテナが起動した状態で、ブラウザから以下のURLにアクセスします。

```text
http://localhost:8000
```

睡眠時間記録アプリの画面が表示されれば、起動成功です。
